# John Padel Academy

Landing page mobile-first y bilingüe para John Padel Academy, publicada en GitHub Pages.

## Sitio

https://edubernardez.github.io/johnpadel/

## Funcionalidades

- Español y portugués con detección automática y preferencia guardada.
- Modalidades y precios de Show Aula, clase individual y dupla.
- Formulario sin backend que crea el mensaje y abre WhatsApp.
- Diseño responsive, imágenes optimizadas, SEO y metadatos sociales.
- HTML, CSS y JavaScript vanilla, sin dependencias de ejecución.

## Vista local

Serví la carpeta con cualquier servidor estático y abrí index.html.
